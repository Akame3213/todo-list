Фокус — настольный список задач на русском языке.

**Скачать:** раскройте раздел **Assets** под этим описанием.

- **Windows 10/11, x64:** скачайте файл `Фокус … .exe` и запустите. Установка не нужна.
- **Linux, x64:** скачайте `.AppImage`, разрешите исполнение файла и запустите. Для AppImage может понадобиться FUSE.

Приложение содержит задачи с приоритетами, проекты, сроки, напоминания, поиск, недельный календарь и резервное копирование.

Данные сохраняются локально. Напоминания работают, пока приложение открыто; пропущенные появляются при следующем запуске. Сборки без цифровой подписи.
