Фокус 2 — задачи, профиль и собственный сервер.

Скачайте **Focus-2.0.0-win-x64.exe** в разделе **Assets** и запустите без установки. Для Linux — AppImage.

Добавлены:
- точное время задачи и напоминания с учётом часового пояса;
- уведомления на компьютер, сворачивание в трей и письма через SMTP;
- новая палитра, светлая, тёмная и системная темы;
- регистрация, вход, подтверждение почты, профиль с фото, описанием и цветом;
- сервер аккаунтов и задач, защита от перезаписи при конфликте версий.

**[Настройка сервера Windows 10 + Gmail](https://github.com/Akame3213/todo-list/blob/main/server/SETUP-WINDOWS.md)**

Сервер устанавливается отдельно из исходников (Source code ZIP ниже). Без сервера доступен локальный режим. Для почты нужны SMTP Gmail, подтверждённый адрес и работающий сервер. Для уведомлений компьютера Фокус должен работать, в том числе в трее. В выключенном или спящем состоянии ПК напоминания не обрабатываются.

Данные предыдущего гостевого режима сохраняются: перед обновлением рекомендуется экспортировать JSON-копию. Для переноса задач в аккаунт импортируйте её после входа. Сборки без цифровой подписи; проверку реальных уведомлений Windows и Gmail выполните на своём ПК по инструкции.
